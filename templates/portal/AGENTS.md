# Portal

This folder is the standard MERIT Portal surface. It is a static marketing and onboarding entry point only.

Rules for agents:

- Keep the surface named `Portal`.
- Edit `portal.json` first; keep HTML, CSS, and JS generic.
- Do not add app code, private keys, tenant secrets, or internal provider implementation details.
- Keep the footer visibly `MERIT Powered`.
- Publish only the `portal/` folder to here.now.
