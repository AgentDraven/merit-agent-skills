Security Architecture

Cloud Centric Security First Solution

M4FI is cloud-first: this Portal is the subscriber entry. Chart apps receive paste files only — never your pass-token or raw vault.

Pass-token encryption (FR-038)

Broker and BYOK secrets encrypt with your meritsubs pass-token (two four-word phrases + four-digit pin). PBKDF2-SHA256 + AES-256-GCM. We never store your pass-token.

Broker API keys — read vs write

  • Sync (default): Read-only position and fill access.
  • Execute w/AI (Pro): Orders only with explicit Portal authorization.

Admin laptop mode

Local CLI sync is for platform admin validation only — not the subscriber default.
