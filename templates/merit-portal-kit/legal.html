5. Security First — PII, KYC, broker keys & BYOK

Our motto: Cloud Centric Security First. We treat subscriber secrets with institutional discipline — minimum exposure, encryption at rest, explicit authorization for writes.

  • PII (email, legal name, contact): Stored in meritsubs only. M4FI receives a sub_handle and tier flags — not identity documents.
  • KYC: Required for paid tiers and community write access. Verification documents remain in meritsubs; M4FI reads entitlement flags only.
  • Broker API keys: Read-only sync for chart geometry. Encrypted with your meritsubs pass-token (FR-038). Never embedded in TradingView Pine or public logs.
  • BYOK: LLM and optional execute tokens stored in the same encrypted vault. Keys unlock only for authorized sessions.
  • Orders / writes: Live broker orders require explicit Portal authorization (Execute w/AI). Default is read-only sync.
